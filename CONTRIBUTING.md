# Contributing to Harmony Aikido Dojo Website

Thank you for your interest in contributing to the Harmony Aikido Dojo website! We welcome contributions that help improve the site while maintaining its peaceful, traditional aesthetic.

## 🤝 How to Contribute

### Reporting Issues

If you find a bug or have a suggestion for improvement:

1. Check if the issue already exists in our [Issues](https://github.com/yourusername/harmony-aikido-dojo/issues)
2. If not, create a new issue with:
   - Clear description of the problem or suggestion
   - Steps to reproduce (for bugs)
   - Expected vs actual behavior
   - Screenshots if applicable
   - Browser and device information

### Making Changes

1. **Fork the Repository**

   ```bash
   git clone https://github.com/yourusername/harmony-aikido-dojo.git
   cd harmony-aikido-dojo
   ```

2. **Create a Feature Branch**

   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**

   - Follow the existing code style and structure
   - Test your changes across different browsers and devices
   - Ensure responsive design is maintained

4. **Test Locally**

   ```bash
   # Open index.html in your browser or use a local server
   python -m http.server 8000
   ```

5. **Commit Your Changes**

   ```bash
   git add .
   git commit -m "Add: brief description of your changes"
   ```

6. **Push and Create Pull Request**
   ```bash
   git push origin feature/your-feature-name
   ```

## 📋 Guidelines

### Code Style

- **HTML**: Use semantic HTML5 elements, proper indentation (2 spaces)
- **CSS**: Follow BEM methodology where applicable, use consistent naming
- **JavaScript**: Use modern ES6+ syntax, add comments for complex logic
- **Responsive**: Ensure all changes work on mobile, tablet, and desktop

### Design Principles

- **Colors**: Stick to the established palette (autumn reds, warm browns, clean whites)
- **Typography**: Maintain the elegant serif font choices
- **Spacing**: Use consistent margins and padding
- **Accessibility**: Ensure proper contrast ratios and keyboard navigation

### Content Guidelines

- **Tone**: Professional yet welcoming, respectful of Aikido traditions
- **Language**: Clear, accessible language suitable for all experience levels
- **Accuracy**: Ensure all Aikido-related information is accurate and respectful

## 🎯 Areas for Contribution

### High Priority

- Accessibility improvements (ARIA labels, keyboard navigation)
- Performance optimizations
- Cross-browser compatibility fixes
- Mobile experience enhancements

### Medium Priority

- Additional interactive features
- SEO improvements
- Content updates and corrections
- Animation refinements

### Low Priority

- Visual enhancements
- Additional pages or sections
- Integration with external services

## 🧪 Testing

Before submitting your pull request:

1. **Cross-Browser Testing**: Test in Chrome, Firefox, Safari, and Edge
2. **Responsive Testing**: Verify on mobile, tablet, and desktop viewports
3. **Accessibility Testing**: Use tools like WAVE or axe-core
4. **Performance Testing**: Check loading times and optimize if needed

## 📝 Pull Request Process

1. **Description**: Provide a clear description of what your PR does
2. **Screenshots**: Include before/after screenshots for visual changes
3. **Testing**: Describe how you tested your changes
4. **Breaking Changes**: Note any breaking changes or migration steps needed

### PR Template

```markdown
## Description

Brief description of changes

## Type of Change

- [ ] Bug fix
- [ ] New feature
- [ ] Breaking change
- [ ] Documentation update

## Testing

- [ ] Tested on Chrome
- [ ] Tested on Firefox
- [ ] Tested on mobile devices
- [ ] Accessibility tested

## Screenshots

[Include relevant screenshots]
```

## 🚫 What Not to Contribute

- Changes that significantly alter the visual design without discussion
- Features that don't align with the dojo's peaceful, traditional aesthetic
- Code that breaks accessibility or responsive design
- Content that misrepresents Aikido principles or practices

## 📞 Questions?

If you have questions about contributing:

- Open an issue for discussion
- Check existing issues and pull requests
- Review the project documentation

## 🙏 Recognition

Contributors will be recognized in our README.md file. Thank you for helping make this website better for the Aikido community!
